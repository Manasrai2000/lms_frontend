LMS Admin Panel - Functional Requirements Document (FRD)
Prepared for Development Team
Version: 1.0
Purpose: Define LMS Admin Panel features and requirements.
1. User Management
•	Manage LMS users and access control.
•	Fields: User ID, Name, Email, Password, School Name, Mobile Number, Role, Created Date, Last Login Date, Status.
•	Actions: Add, Edit, Delete, Reset Password, Activate/Deactivate, Search, Filter.
2. Permission Management
•	Book Permissions: Assign accessible books to users.
•	Module Permissions: Control visibility of Dashboard, Books, Question Bank, Videos, Worksheets, Reports, etc.
•	Support bulk assignment and permission updates.
3. Question Type Management
•	Create and manage question categories.
•	Types: MCQ, True/False, Fill in the Blanks, Match the Following, Short Answer, Long Answer, Essay, Case Study, Practical, Project Work.
•	Fields: Question Type Name, Default Marks, Description, Status.
4. Book Management
•	Manage Books, Chapters, Worksheets, Videos, Teacher Manuals, Lesson Planners, Flipbooks and Current Affairs.
•	Support upload, view and download operations.
5. Question Import / Export
•	Export questions using Class, Subject, Book, Chapter and Question Type filters.
•	Export formats: Excel, CSV, PDF.
•	Import questions via Excel template with validation and duplicate detection.
6. QR Code Generator
•	Generate QR codes for Books, Chapters, Worksheets, Videos, Teacher Manuals and Flipbooks.
•	Support PNG, SVG and print-ready downloads.
•	Bulk QR generation supported.
7. Reports & Audit Logs
•	User Activity Reports, Book Access Reports, Question Usage Reports.
•	Track user actions and system changes.
8. Dashboard
•	Display key statistics including Users, Books, Questions, Videos and Worksheets.
•	Recent activity monitoring.
